# 정렬 (Alignment)

## 개요

**정렬(Alignment)** 은 [[C-Chasm]] IP의 핵심 용어로, 기존 크툴루 신화의 "봉인(Seal)" 개념을 대체한다. [[아자토스의_꿈_패턴]]이 안정적으로 유지되는 상태를 가리키며, 비인격적 현상임을 표현한다.

## 용어 전환의 근거

"봉인"이라는 단어가 가진 문제점:
- **인격적 행위자 함의**: "누군가가 가두었다"는 의미를 내포
- 심층에서 그레이트 올드 원의 수면 상태는 행위자 없는 현상 — 꿈 패턴이 자기 안정화하는 과정

"정렬"이 적절한 이유:
- 비인격적 자동 작용을 정확히 표현
- 패턴이 정렬된 상태 / 정렬이 어긋난 상태로 직관적 이해 가능

## 용어 체계

| 과거 용어 (봉인) | C-Chasm 용어 (정렬) |
|-----------------|-------------------|
| 그레이트 올드 원이 봉인되어 있다 | 그레이트 올드 원이 정렬 하에 있다 |
| 봉인이 약해진다 | 정렬 임계가 하락한다 |
| 봉인 해제 | 정렬 해제 / 부정렬 |
| 봉인 강화 | 정렬 강화 |
| 봉인 약화의 징조 | 정렬 어긋남의 징조 |
| 별이 바르게 놓일 때 | 정렬 임계 하락 시기 |

## 서사적 활용

### 내부 설계에서의 사용

C-Chasm의 모든 설정 문서·내레이션은 "정렬"을 사용한다. "봉인"이라는 단어는 원칙적으로 사용하지 않는다.

### 예외 — 인간 컬트 문헌 인용

작중 인간 컬트가 이 현상을 "봉인"이라 기록하는 것은 허용된다. 이는 인간 인식의 얄팍함을 직접적으로 표현하는 장치다.

플레이어 경험 구조:
1. 초기에 컬트 문헌에서 "봉인"을 접함
2. 연금술 단계 상승에 따라 [[회귀형_신]]들이 "정렬"을 언급
3. 플레이어가 스스로 왜곡을 발견

이 발견 과정 자체가 [[C-Chasm]]의 핵심 체험이다.
