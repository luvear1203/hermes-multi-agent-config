# 신의 세 유형

## 개요

[[C-Chasm]] 우주에서 모든 **하위 신화 개별 신격**은 심층 진실에 대한 인식과 태도에 따라 세 유형으로 분류된다. 이 분류는 [[C-Chasm_우주론]]의 표층/심층 구조에서 파생된 인식론적 분류이며, 신의 성격이나 도덕성이 아니라 우주의 본질을 마주한 결과다.

중요: 본 분류는 하위 신화 개별 신격에만 적용된다. 매크로 팩션 구조([[c-chasm-ip-core]] Part 1-4 참조)의 엘더갓·아우터갓·그레이트 올드 원은 벡터 수준에서 정렬되며 본 분류 대상이 아니다.

## 강림형 (降臨型) — 모르는 신

| 항목 | 내용 |
|------|------|
| 인식 상태 | 심층 진실을 모른다. 표층 법칙(신앙=존재) 안에서만 사고 |
| 태도 | 신앙 회복을 위해 인간 세계에 직접 개입 |
| 행동 | 재난·기적·초자연 현상으로 자신의 존재를 각인 |
| 논리 | "인간이 나를 인식하면 나는 존재한다" |
| 위험도 | 높음 (대규모 인적·환경 피해) |
| 본질 | 가장 무지하지만 가장 인간적이다 |

강림형은 표면적으로 가장 강력한 적이지만, 자신이 무엇인지 모르기 때문에 끝까지 자기 자신일 수 있는 **가장 순수한 존재**다. 제우스, 토르, 인드라 등이 대표적이다.

## 회귀형 (回歸型) — 알고 순응한 신

| 항목 | 내용 |
|------|------|
| 인식 상태 | 심층 진실을 알게 되었고 받아들였다 |
| 태도 | 소멸을 받아들이되 마지막에 유산을 남기려 함 |
| 행동 | 권능·지식·기억을 특정 인간이나 장소에 남기고 소멸 |
| 논리 | "사라지는 것이 자연스럽다. 그러나 사라지기 전에 할 수 있는 일이 있다" |
| 위험도 | 낮음 (직접 피해 없음) |
| 본질 | 선의는 진심이지만, 그 선의조차 패턴 정렬의 자동 작용일 가능성을 안다 |

회귀형의 비극성은 자신의 행위가 우주적 의미를 가지지 못함을 알면서도 **인간 척도의 의미를 위해** 행동한다는 데 있다. 토트(작품문서 예정, 현재 미작성), 오딘, 벨레스 등이 대표적이며, 이들은 [[본편_RPG_(C-Chasm)]]의 주인공 [[아담]]을 설계한 주체다.

회귀형 내에는 인식 등급 차등이 존재한다:
- **고위**: 꿈 패턴 직접 인식 + 매크로 팩션 존재 감지
- **중위**: 꿈 패턴 인식 + 매크로 팩션 존재만 감지
- **하위**: 꿈 패턴만 감지

## 광기형 (狂氣型) — 알고 거부한 신

| 항목 | 내용 |
|------|------|
| 인식 상태 | 심층 진실을 알게 되었고 거부했다 |
| 태도 | 인정의 거부가 정신의 붕괴로 발현 |
| 행동 | 무차별 파괴. 자신의 신화권조차 초토화 |
| 논리 | 없음. "나는 여기 실재한다"는 자기 증명의 발작만 남음 |
| 위험도 | 최고 |
| 본질 | 광기는 약함이 아니라 진실을 본 자의 발작 |

광기형은 단순한 빌런이 아니라, 인간이 마주해서는 안 되는 진실을 마주한 자들의 잔해다. 격파 후에도 카타르시스 대신 씁쓸함만 남는다.

## 유형 간 이행

- 강림형 → 회귀형: 진실을 알고 순응 (가장 평화로움)
- 강림형 → 광기형: 진실을 알고 거부 (가장 흔하고 비극적)
- 회귀형 → 광기형: 받아들였다 믿었으나 견디지 못함 (가장 잔혹)
- 광기형 → 회귀형: 거의 불가능

유형 이행은 [[C-Chasm]] 작품 내에서 강력한 서사 장치로 기능한다. 회귀형 신은 [[회귀형_신]] 개별 페이지 참조.
