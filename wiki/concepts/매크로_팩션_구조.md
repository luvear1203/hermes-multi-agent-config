# 매크로 팩션 구조

## 개요

매크로 팩션 구조는 [[C-Chasm 우주론]]의 심층 차원에서 작동하는 거시 벡터 체계다. [[아자토스의 꿈 패턴]]에서 자기 결정화되어 발생한 두 개의 벡터 진영이 존재하며, 이들은 개별 신격이나 조직이 아닌 **방향성** 자체다.

중요: 매크로 팩션은 하위 신화 층위와 완전히 분리된다. [[신의 세 유형]] 분류는 매크로 팩션에 적용되지 않는다.

## 3층위 구조

```
[최상층] 아자토스 — 꿈꾸는 자
    │
[거시 벡터 층위]
 ├── 엘더갓 진영 (안정화 벡터)
 │      - Hypnos, Nodens (인격 현현 가능)
 │      - Nyctelios (유폐 상태)
 │      - 기타 엘더갓 다수 (벡터 자체로만 존재)
 │
 └── 아우터갓 진영 (불안정화 벡터)
        ├── 상위 인격 현현: 나이알라토텝, 요그소토스, 샵니구라스, Ubbo-Sathla
        └── 그레이트 올드 원: 크툴루, 하스터, Ithaqua, 다곤 등
```

## 핵심 원칙

### 선악 부재 원칙

엘더갓 진영은 선이 아니며, 아우터갓 진영은 악이 아니다. 두 진영은 단지 벡터 방향이 다를 뿐이다. 인간 척도가 벡터 방향을 선악으로 번역하는 것은 자연스러우나, **내레이션과 IP 설계 층위에서는 선악 구도를 채택하지 않는다**.

### 벡터와 개체의 관계

벡터(진영) 자체에는 의지가 없으나, 벡터 내부 개체는 독자 의지·동기를 가질 수 있다. 이 구분이 C-Chasm 서사의 풍부함을 보장한다.

예: 아우터갓 진영 소속 Ithaqua가 같은 진영의 Ubbo-Sathla 살해에 협력 — 진영 내부 파벌 충돌.

## 하위 신화 독립 원칙

매크로 팩션 층위와 하위 신화 층위는 **완전히 분리**된다. 핵심 규칙:

1. **층위 분리**: 엘더갓·아우터갓·그레이트 올드 원과 하위 신화 신격은 존재론적으로 별개다.
2. **동명이인 분리**: 이름이 같아도 별개 존재다 (예: 그리스 Hypnos ≠ 엘더갓 Hypnos).
3. **인간 전승 혼동 허용**: 인간 문헌이 두 층위를 혼동하는 것은 서사 자산으로 활용된다.
4. **내레이터 분리**: 설정 문서·3인칭 내레이션에서는 반드시 분리 서술한다.

## 주요 개체

### 엘더갓 진영

- **Hypnos**: 인격 현현 가능. [[C-Chasm Alpha]] 주인공의 창조주. 꿈속 내레이션 담당.
- **Nodens**: 인격 현현 가능하나 C-Chasm 작중 미사용.
- **Nyctelios**: 유폐 상태. [[본편 RPG (C-Chasm)]] 그리스 구역 배경 개체.

### 아우터갓 진영 (상위 인격 현현)

- **나이알라토텝**: Crawling Chaos. 가장 활동적인 아우터갓.
- **요그소토스**: 시공간의 화신.
- **Ubbo-Sathla**: 무의식 보관자. 엘더 기록을 체내에 응축.

### 그레이트 올드 원 (아우터갓 진영 산하)

- **크툴루**: R'lyeh 해저. 정렬 하 수면.
- **하스터**: King in Yellow. [[C-Chasm Alpha]] 최종 보스.
- **Ithaqua**: 북극. 진엔딩에서 주인공 조력자.
- **다곤 & Deep Ones**: 해양 세력.
