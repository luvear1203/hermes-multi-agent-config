# Mythrill 문서 컨벤션

Mythrill 파이프라인 프로젝트의 모든 `.md` 문서에 적용되는 작명·구조·메타데이터 규칙. 옵시디언 그래프뷰 중심의 문서 관리와 Claude MCP의 효율적 탐색을 위해 설계되었다.

## 단일 진실 소스 원칙

```
[00_시스템코어/시스템정의_v1_0.md]
        │ (단방향 참조)
        ↓
[10_공모전_루키2026/]    [20_검증/]    [30_사업화/]
```

- 시스템 코어는 활동 문서를 참조하지 않는다.
- 활동 문서는 시스템 코어를 참조하되, 위반할 수 없다.
- 활동 폴더 간에는 서로 직접 참조하지 않는다 (코어를 경유).
- 충돌 시 항상 시스템 코어가 우선.

## 파일명 형식

```
[번호prefix]_[분류]_[고유명]_v[버전].md
```

### 번호 prefix 체계

| 범위 | 용도 |
|------|------|
| 00번대 | 코어·정체성 |
| 01~09 | 메인 작업 문서 |
| 10~19 | 신청서 본문 항목 |
| 20~29 | 신청서 부속 자료 |
| 80~89 | 참고자료·외부 데이터 |
| 90~99 | Q&A·반박 대비·보조 |

### 사용 문자

- 한글 사용 허용
- 공백 금지. 단어 구분은 언더스코어(`_`)
- 특수문자 금지. `-`, `_`만 허용
- 버전 표기: `v1_0` (점 대신 언더스코어, 옵시디언 위키링크 호환성)

## YAML Frontmatter 필수 필드

```yaml
---
ip: Mythrill
work: 시스템코어        # 시스템코어 | 공모전 | 검증 | 사업화 | 인덱스 | archive
category: 정의          # 정의 | 아키텍처 | 신청서 | 검증 | 로드맵 | 사업자 | QnA | 인덱스 | archive
status: 확정            # 확정 | 검토중 | 미정 | archived
version: 1.0
created: 2026-04-27
updated: 2026-04-27
---
```

## 버전 관리 규칙

| 상황 | 처리 |
|------|------|
| 마이너 수정 (오타·문구) | 같은 파일 직접 수정, `updated`만 갱신 |
| 마이너 변경 (내용 추가) | `version` 0.1 증가 |
| 메이저 변경 (구조·핵심 정의) | 새 파일 생성. 구버전은 `99_archive/`로 이동 |
| 폐기 | `99_archive/`로 이동, prefix `archive_` 추가 |

## Claude / MCP 사용 가이드

Claude는 다음 우선순위로 문서를 검색:

1. 본 인덱스 (`_INDEX.md`) — 프로젝트 전체 좌표
2. 활동 폴더의 `_INDEX.md` — 활동 내 좌표
3. 시스템 코어 (`시스템정의_v1_0.md`) — 상위 제약 확인
4. 활동 내 세부 문서 — 구체 답변
5. `99_archive/` — 별도 지시 없이 참조하지 않음

### 토큰 효율 분할 원칙
- 한 작업에 필요한 문서만 로드
- 신청서 단일 항목 작업: 해당 항목 파일 + 시스템 코어 + 활동 인덱스만
- 시스템 차원 작업: 시스템 코어 + 본 인덱스 + 영향받는 활동 인덱스만
