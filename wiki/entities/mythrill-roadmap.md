# Mythrill 장기 로드맵

Mythrill 파이프라인의 플러그인에서 독자 게임 엔진까지의 5단계 비전.

## 전체 비전

**플러그인 → 툴킷 → 자체 에디터 → 자체 렌더러 → 독자 게임 엔진**

역사적 검증 패턴: Unity, Unreal, Houdini, Blender 모두 작은 도구에서 출발해 점진 확장.

## 5단계 로드맵

### Phase 1 (현재 ~ 1년): MVP 플러그인
- 공모전 출품 (루키 2026)
- 인디용 AI VFX 플러그인 1차 버전 (언리얼 한정)
- 언리얼 마켓플레이스 출시
- 솔버 1~2개 + 물질 5~10개 지원

#### Phase 1 세부 추진일정 (도전제안서 수정본 3.3)

| 시점 | 작업 | 산출물 |
|------|------|--------|
| 2026.5~6 | **2차 스파이크** ([[llm-separation-design|LLM ②]] SI 단위 매핑) | 30회 검증 + 물질 5종(물·점성액·모래·연기·촛농) 파라미터 라이브러리 초안 |
| 2026.7~8 | **MVP 핵심 파이프라인** | 자연어 → Taichi MPM → Flipbook 단일 흐름 + 사용자 확인 UI + [[three-branch-regression|3분기 점검]] |
| 2026.9~10 | **언리얼 연동** | Flipbook/VAT 자동 임포트 플러그인 + [[mythrill-rpg-showcase|Living Showcase]] 첫 이펙트 3종 적용 |
| 2026.11~2027.1 | **외부 검증** | 인디 개발자 5~10인 베타 + 물질 라이브러리 20종+ 확장 |
| 2027.2~3 | **공개 배포** | 문서·설치 스크립트 정비 + 언리얼 마켓플레이스 또는 GitHub 오픈소스 배포 |

### Phase 2 (1~2년): 플러그인 기능 확장
- 유체·파괴·연기·입자 통합 툴킷
- 솔버 종류 확장 (DEM, 열 시뮬 등)
- 물질 라이브러리 50+ 확장
- 유니티 포팅

### Phase 3 (2~3년): 자체 에디터 GUI
- 게임 엔진 외부에서도 사용 가능한 독립 도구
- 베이크 결과 미리보기 자체 렌더링
- 디자이너 협업 기능

### Phase 4 (3~5년): 자체 렌더러 + 런타임 통합
- 실시간 미리보기 자체 렌더러
- 일부 효과 런타임 재생 지원
- 게임 엔진 의존도 감소

### Phase 5 (5~10년): 독자 게임 엔진
- VFX 중심에서 게임 엔진 전체로 확장
- 신화 RPG 같은 특정 장르 특화 엔진 가능성

## 주요 결정 포인트

**Phase 2 → 3 점프가 가장 위험.** 플러그인 회사로 남느냐, 독자 도구 회사로 가느냐의 갈림길. 이 시점의 결정 기준:

- 플러그인 사용자 수
- 월 매출
- 팀 규모
- 시장 변화 (Epic·Unity의 AI 통합 진척도)

## 단계 독립성 원칙

각 단계를 독립적으로 가치 있게 설계. 학부생 + 수입 없음 + 현실 변수(졸업·병역·취업)를 고려해 각 단계가 단독으로 의미 있어야 중간 중단 시에도 손실 최소화.

| 단계 | 단독 가치 |
|------|----------|
| Phase 1 | 수상 실패해도 졸업작품/포트폴리오 |
| Phase 2 | 마켓플레이스 매출 / 게임사 라이선스 |
| Phase 3 | SaaS 사업 가능성 |
| Phase 4~5 | 자원 확보 후 결정 |

## AI 차별점 유효 기간

- **현재**: AI 네이티브 도구가 차별점
- **2~3년 뒤**: AI 기능이 모든 도구의 기본 사양. 물리 정합성 특화, 장르 수직 통합, 오픈소스 + 커뮤니티 모델로 전환 검토

## 피칭 전략

**외부 발표에서는 다음 한 걸음만 말한다.** 학부생이 "Unity 같은 엔진 만들겠다" 발언은 리스크 평가 모드로 전환됨.

- Phase 1 피칭: "인디용 AI VFX 플러그인"
- Phase 2 피칭: "인디용 통합 VFX 툴킷"
- Phase 3 피칭: "독자 VFX 작업 환경"
