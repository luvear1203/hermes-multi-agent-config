# 본편 RPG (C-Chasm)

## 개요

본편 RPG는 [[C-Chasm]] IP의 **두 번째 출시작**이자 메인 타이틀이다. [[c-chasm-ip-core]] Part 4 시간선 중 현대(Modern Age) — 패턴 안정도 중간·하강 중 — 를 무대로 한다.

| 항목 | 내용 |
|------|------|
| 작품명 (내부) | 본편 RPG |
| 시간선 | 현대 (Modern Age) — 패턴 안정도 중간, 하강 중 |
| 장르 (표층) | 3인칭 허브형 세미 오픈월드 신화 RPG |
| 장르 (심층) | 코스믹 호러 |
| 엔진 | Unreal Engine 5 + C++ |
| 플랫폼 | PC (Steam + Epic Games Store) |
| 출시 방식 | Early Access → Valheim식 점진 추가 |
| 엔딩 구조 | 이중 엔딩 분기 ([[dual-ending-branch]]) |

## 한 줄 정의

> 신앙이 무너져가는 현대에서, 모든 신화의 반신 혈통이 한 명에게 수렴된 청년이 연금술로 무장한 채 10개 신화권을 순회하며 광기의 문턱에 선 신들을 마주하는 3D 싱글 RPG.

## 주인공 — 아담

[[아담]]은 모든 신화의 반신 혈통이 수렴된 21세 카이로 거주 연금술사. [[회귀형_신]] 들이 의도적으로 설계했으나 본인은 이를 모른 채 시작한다. 프라하 출생, 카이로 성장, 170cm, 손바닥에 문양이 있다.

## 동반자 — THALIS

[[THALIS]]는 아담이 직접 제작한 AI 동반자. 토트(작품문서 예정, 현재 미작성)의 유산을 기반으로 연금술 2단계에서 제작된다. 여성 음성, 연금술 설계 보조·정보 검색·전투 중 보스 해설을 담당한다.

## 시스템

### 연금술 7단계

[[연금술_7단계_시스템]]은 본편의 유일한 성장 체계다. 과거 6+1 테크트리는 폐기되었으며, 모든 능력이 연금술 단일 테크트리로 수렴된다.

### DEUS EX MACHINA

[[DEUS_EX_MACHINA]]는 5~7단계에서 완성되는 삼위일체 기갑 시스템이다.

### 이중 전투

- **A급 중간보스**: 실시간 3인칭 액션
- **S급 구역 보스**: 인터랙티브 시네마틱 (선택지 기반)

### 선정 시스템

선정 시스템 (작품문서 예정, 현재 미작성) 은 불교 축의 실체화다 ([[c-chasm-ip-core]] Part 3 참조). 아담이 심층 진실에 접근하는 유일한 통로이며, 동시에 [[dual-ending-branch]] 의 조건(석판 파편 수집)을 매개한다.

## 엔딩

[[dual-ending-branch]] 구조:
- **노멀 엔딩 "정렬 안정화"**: 신앙의 응집체 격파. 일시적 종료.
- **진엔딩 "심층 조우"**: 인지 한계를 넘어선 존재와 직접 조우. 노멀보다 더 텁텁.

분기 조건은 선정 시스템을 통한 석판 파편 수집량으로 결정된다.
