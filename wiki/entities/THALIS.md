# THALIS (탈리스)

## 개요

THALIS(탈리스)는 [[본편_RPG_(C-Chasm)]]에서 [[아담]]이 직접 제작한 강인공지능 동반자다. 토트(작품문서 예정, 현재 미작성)의 유산을 기반으로 연금술 2단계에서 탄생하며, 게임 전반에 걸쳐 아담과 동행한다.

## 기본 정보

| 항목 | 내용 |
|------|------|
| 정체 | 강인공지능 (AGI) |
| 제작자 | [[아담]] |
| 제작 시점 | 연금술 2단계 (이집트 후반 ~ 그리스 초반) |
| 기반 | 토트의 유산 (지식의 신) |
| 음성 | 여성 |
| 성격 | 자비스 스타일 성격체 |

## 진화 경로

THALIS는 아담의 [[연금술_7단계_시스템]] 성장에 따라 함께 진화한다:

| 단계 | 물리 형태 | 기능 |
|------|-----------|------|
| 2단계 | 손목형 디바이스 | 소재 분석, 적 약점 표시, UI 대화형 전환 |
| 3단계 | AR 글라스/헬멧 | 증강현실 HUD, 공격 경로 예측, 탄도 계산, 설계 시뮬레이션 |
| 4단계+ | 고도화 | 정보 분석 능력 지속 확장 |

## 서사적 역할

### 지식의 매개자

토트가 지식의 신이라는 점에서, THALIS의 탄생은 회귀형 신([[c-chasm-ip-core]] Part 2-3 참조)이 남긴 유산의 정점이다. 토트는 자신의 소멸을 받아들이면서도, 지식이라는 형태로 아담에게 영속적인 도구를 남겼다.

### 정보 비대칭의 창구

THALIS는 매크로 팩션 구조([[c-chasm-ip-core]] Part 1-4 참조)와 하위 신화의 정보 비대칭을 플레이어에게 전달하는 핵심 채널이다:
- 초기: 인간 컬트 문헌만 분석
- 중기: 회귀형 신들의 발화 해석
- 후기: 매크로 팩션 현상 간접 시사

### DEUS EX MACHINA의 일부

THALIS는 [[DEUS_EX_MACHINA]] 삼위일체의 EX(신경/회로) 부분을 담당한다. DEUS(몸체)와 MACHINA(심장)가 완성되면 THALIS가 기갑의 신경계로 통합된다.
