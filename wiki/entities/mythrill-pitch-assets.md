# Mythrill 피칭 자료 — 이미지 에셋 준비

[[ai-rookie-2026]] 심사 피칭용 [Prompt → Actual Asset Scene] 시각 예시 2건의 준비 계획.

## 정직 프레임 (반드시 유지)

피칭 시 동작 범위를 분리해서 표시해야 한다.

| 구성 요소 | 상태 |
|---|---|
| LLM ① (자연어 → 단계 JSON) | **검증 완료** ([[llm1-validation]] v3 동결, 91.3% 정확도) |
| 1차 스파이크 (자연어 → 14필드 스키마) | **100% 통과** ([[mythrill-spike-01]]) |
| LLM ② (단계 JSON → SI 단위 물리 파라미터) | **2026-05-09 착수 예정** ([[mythrill-spike-02]]) |
| MPM 단일 솔버 + 구성방정식 동적 스왑 | **2026 EOY MVP 목표** |
| Flipbook/VAT 베이크 + UE5 임포트 | **2026 EOY MVP 목표** |

따라서 이번 피칭의 두 [Prompt → Asset Scene] 예시 이미지는:
- LLM ① 출력 패널은 실제 검증 결과 사용 (50입력 검증의 진짜 JSON)
- 최종 렌더 이미지는 **타겟 컨셉 렌더(목업)**, "본 파이프라인이 EOY 까지 도달할 출력 기준점" 으로 명시
- 심사위원 질의 대비: "현 단계에서 LLM ① 까지는 동작, LLM ② + 솔버 + 렌더는 5월 9일 착수 후 EOY 완성 예정. 1차 스파이크 30회 100% 통과로 핵심 가설 입증 완료."

## 선정 페어 (확정 전)

### 후보 페어 1 — 단순 + 다단계 조합 (추천)

**A. 단순 · 아이코닉**
- 입력: "황금빛 광채를 뿜는 신성한 검의 오라" (`inputs.txt` #4)
- 카테고리: `1stage_visual_direct` (1단계, 시각 직접)
- 검증 결과 (v3): claude 89%, deepseek 89%, gemini 100%
- 가치: 한 장 이미지로 임팩트 명확. 마법·게임 친화. 게임 VFX 친숙도 ↑.

**B. 복잡 · 다단계** (LLM ① 가치 노출)
- 입력: "마법진이 발동되어 빛이 모이고 회전하다 사방으로 폭발하며 잔향이 천천히 가라앉음" (`inputs.txt` #41)
- 카테고리: `2stage_time` (v3 라벨, 시간 기반 다단계). 본문엔 사실상 5국면 (응축 → 회전 → 폭발 → 잔향 → 감쇠)
- 검증 결과 (v3): 3모델 모두 100%
- 가치: 자연어 한 문장이 시간축 시퀀스로 분해되는 LLM ① 핵심 가치를 1슬라이드 4컷 시퀀스로 직시.

### 대안 페어

- A2. "용암 동굴 천장에서 흘러내리는 마그마" (#9) — 물리적 임팩트, MPM 솔버 강점 시각화에 적합
- B2. "검에 깃든 룬이 점점 빛나다 폭발적으로 확산되고 검 주위로 다시 응축되어 회수됨" (#42) — 순환 구조, 일관된 단일 객체 위에서 다단계 변화 노출

## 슬라이드 구성안 (1 페어당 1 슬라이드)

```
┌─────────────────────────────────────────────┐
│ INPUT (자연어 한 줄)                        │
│   "..."                                     │
│                                             │
│ ─────────── LLM ① (검증 완료) ──────────    │
│   stages: [{behavior, trigger, material}]   │
│   visual: {color, emission, inferred}       │
│   ※ 50입력 검증 데이터에서 실제 JSON 인용   │
│                                             │
│ ─────────── LLM ② + MPM (EOY 목표) ─────    │
│   → SI parameter set                        │
│   → solver step + 구성방정식 스왑           │
│                                             │
│ OUTPUT (타겟 컨셉 렌더)                    │
│ [             대형 이미지 영역             ] │
└─────────────────────────────────────────────┘
```

## 분담

- **사용자**: 시각 디렉션 + 컨셉 렌더 이미지 생성 (도구 미정 — 후보: ComfyUI 클라우드 / Midjourney / SDXL)
- **AI (Director)**: 슬라이드 레이아웃 HTML/SVG 템플릿, LLM ① JSON 패널 텍스트 인용·정렬, 톤 일관성 검수, 정직 프레임 문구 정합성 확인

## 결정 대기 항목

1. 페어 확정 (후보 페어 1 / 대안 페어 1·2 / 다른 조합)
2. 이미지 생성 도구
3. 슬라이드 톤 — 정직 모드(렌더는 타겟 컨셉 명시) vs 완성형 모드(목업 표시 안 함, 단 심사위원 질의 시 정직 프레임으로 답변)
4. 출력 형식 — 단독 슬라이드 .png 1장씩 / 통합 PPTX / 통합 PDF
