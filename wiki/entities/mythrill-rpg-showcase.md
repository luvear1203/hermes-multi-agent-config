# Mythrill RPG Living Showcase

Mythrill 파이프라인의 첫 사용자이자 살아있는 쇼케이스 역할을 하는, 본인의 신화 기반 1인 RPG 게임 프로젝트.

## 자리의 의미

- 일반적 도구 사업: 외부 사용자에게 도구를 팔고, 그들의 결과물이 도구의 증명
- 본 시스템: **본인이 도구를 만들면서 동시에 본인 RPG에 적용**. 도구의 첫 사용자이자 최강 검증자.

## 차별점으로서의 가치

- 도구 개발자가 실제 게임 개발 현장의 페인포인트를 직접 겪으며 도구 개선
- "이 도구로 만든 게임이 실제로 출시·판매됨"이라는 단일 사례가 가장 강력한 마케팅
- 본인 RPG의 출시 자체가 도구의 검증 데이터

## 단계별 시너지

- **Phase 1 (공모전~MVP)**: 도구 개발 우선. RPG는 구상 단계.
- **Phase 1 후반 (공모전 후)**: 본인 RPG 첫 장면 1개 제작 → 베이크 자산 5~10개 적용 → 도구 검증 데이터 확보
- **Phase 2 (툴킷)**: RPG 본격 개발 + 도구 기능 확장 병행
- **Phase 3+ (자체 에디터/엔진)**: RPG 시리즈 출시 + 도구 SaaS 사업

## RPG 제품 계획

| 단계 | 내용 |
|------|------|
| 2D 프리퀄 | 선출시, IP 축적용 |
| 3D 본편 | 모델링 진행하며 개발, 얼리액세스 출시 |
| 업데이트 모델 | Valheim 모델 참조, 볼륨 확장하며 가격 상향 |

## 시간 배분

- 공모전 진행 중: 공모전 80%, RPG 20%
- 공모전 마감 후: RPG 50%, 도구 50% (RPG 자산이 도구 검증에 직접 사용)
