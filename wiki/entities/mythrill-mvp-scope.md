# Mythrill MVP 스코프

[[ai-rookie-2026]] 도전제안서 수정본의 2.1·3.1·3.2 항목에서 정의한 MVP 단계 범위. Phase 1 ([[mythrill-roadmap]]) 1년 안에 완성할 최소 동작 시스템의 경계.

## 한 줄 정의

자연어 입력 → Taichi MPM 시뮬레이션 → Flipbook 베이크 출력의 단일 흐름을, 5~10개 물질 라이브러리와 [[naked-viewer|Naked 뷰어]] 사전 확인 UI로 감싼 언리얼 5 플러그인.

## 2026 EOY MVP 종착점

**진짜 마감은 2026-12-31.** [[ai-rookie-2026|공모전]] 결과(합격/불합격)는 일정의 변동 사유가 아니다. 8개월 윈도우(2026-05-03 → 2026-12-31) 안에서 본 페이지의 "MVP"는 다음 상태를 의미한다.

| 상태 | 포함 여부 |
|------|-----------|
| 자연어 → Taichi MPM → Flipbook 단일 흐름 동작 | **포함** (7~8월) |
| Naked 뷰어 + 사용자 확인 ② UI + [[three-branch-regression|3분기 회귀]] | **포함** (7~10월) |
| 언리얼 5 자동 임포트 플러그인 + Lit 모드 검토 | **포함** (9~10월) |
| 물질 5종 (물·점성액·모래·연기·촛농) 파라미터 라이브러리 | **포함** (5~6월) |
| [[mythrill-rpg-showcase|RPG]] 첫 이펙트 3종 자체 적용 (도구 자체 검증) | **포함** (9~10월) |
| 11~12월 폴리시·안정화 | **포함** |
| 외부 인디 개발자 베타 5~10인 | **불포함** (2026.11~2027.1, EOY 후) |
| 물질 라이브러리 20종+ 확장 | **불포함** (EOY 후) |
| 마켓플레이스/GitHub 공개 배포 | **불포함** (2027.2~3) |

즉 **EOY 기준 MVP = "혼자 쓸 수 있는 동작 시스템 + 자체 RPG 첫 이펙트 3종 적용".** 외부 검증·물질 확장·공개 배포는 후속.

일정 압박 발생 시 잘라낼 우선순위: 추가 물질(5종 → 6~10종) 확장 → 베이크 파라미터 분류 로직 자동화 → 언리얼 Lit 모드. **Naked 모드와 Taichi MPM 단일 흐름은 절대 잘라내지 않음.**

## 사용자 플로우 (도전제안서 2.1)

1. 프롬프트 입력 → 사용자가 원하는 고품질 이펙트 생성 시작
2. [[llm-separation-design|LLM ①]]: 프롬프트 분석 + 비현실적 거동에 가장 적합한 물질 선정
3. **사용자 확인 ①**: 의도와 선정 물질 재확인
4. [[llm-separation-design|LLM ②]]: 조정 가능 파라미터 수 설정 + 구성방정식 선택 + Taichi MPM 시뮬레이션 + 색·투명도·빛 적용
5. [[naked-viewer|Naked 뷰어]] 사전 재생 + 승인 요청
6. 승인 후 **베이킹** → 고품질 에셋 출력

## MVP 검증용 테스트 프롬프트 (5종)

도전제안서 2.1에서 명시. 각 프롬프트는 시스템의 특정 능력을 검증.

| # | 프롬프트 | 검증 대상 |
|---|----------|-----------|
| 1 | 사방으로 나선형을 그리며 폭발하듯 퍼져나가다 끝부분이 재처럼 바스라지는 푸른빛 불꽃 | 입자 속도·수명·시간에 따른 색 변화 |
| 2 | 바닥에 닿자마자 무겁게 깔리며 지형을 따라 서서히 번져나가는 짙은 녹색의 맹독 안개 | 입자가 아닌 부피 처리·현실 법칙 조정 |
| 3 | 공중에서 무겁게 떨어져 바닥에 질척하게 튀어 오르고, 서서히 식어가며 빛을 잃는 용암 덩어리 | 점성·형태 붕괴 |
| 4 | 허공을 가를 때마다 날카로운 초승달 모양으로 공간을 일그러뜨리며 찰나의 순간 나타났다 사라지는 황금빛 검기 | 특정 모양·궤적 생성 |
| 5 | 허공에서 끈적한 핏방울처럼 뚝뚝 떨어지다, 바닥에 닿는 순간 반투명하고 날카로운 붉은색 결정체로 얼어붙는 살기 | 상 변화 + 최종 종합 |

이 5종은 `inputs.txt`의 50입력([[llm1-validation]])과는 별개로, **MVP 동작 검증** 단계에서 자연어 → 베이크 에셋 단일 흐름을 파일럿하기 위한 시드 프롬프트.

## 기술 스택 (도전제안서 3.1)

- **언어**: Python 기반 (AI 코드 작성 친화 + 물리 계산 유리)
- **물리 솔버**: [Taichi](https://www.taichi-lang.org/) (MIT License) MPM
  - 유체·고체·입자 거동 단일 프레임워크 처리
  - 시뮬레이션 중 입자별로 [[mpm-constitutive-equation-swap|구성방정식 동적 교체]]
  - 흘러내림→응고 같은 상전이를 단일 솔버 안에서 표현
- **구성방정식**: Carreau-Yasuda (비뉴턴 유체) / Arrhenius (온도 의존 점성) 등 ([[llm-separation-design]] 참조)
- **LLM API**: Claude / Gemini / GPT 중 선택 (제안서 2.3)
- **출력 포맷**: Flipbook (1순위), VAT (3D 메시 변형 시)

## 도전과제 3종과 해결방안 (도전제안서 3.2)

### ① LLM → SI 단위 물리 파라미터 정밀도

**해결**: **2026-05-09 즉시 [[mythrill-spike-02|2차 스파이크]] 착수** — 자연어 → 솔버·SI 단위 파라미터 매핑 30회 검증. [[mythrill-spike-01]]·[[llm1-validation]]에서 LLM ① 신뢰성(spike-01 100% / 50입력 91.3%)은 입증되어 v3에서 동결됐으므로, 동일 검증 프레임을 LLM ②로 이전.

5월 8일 공모전 신청서 제출 다음 날부터 즉시 시작해야 6월 말 라이브러리 초안 완성 후 7~8월 MVP 핵심 파이프라인 일정과 맞물림. 본 단계 지연은 [[mythrill-roadmap]] Phase 1 전체 도미노.

> 제안서 3.2 본문은 "1차 스파이크"로 표기되어 있으나, 3.3 일정 및 [[llm-separation-design]] 정의상 LLM ② 검증은 **2차 스파이크**가 정확. 제안서 본문 오기로 판단.

### ② 시뮬레이션 → 베이크 에셋 품질 보존

**해결**: 이펙트 특성(입자 수·이동 속도·중요도)에 따라 **해상도와 프레임 레이트를 자동 조정하는 베이크 파라미터 분류 로직**을 MVP 단계에서 구현.

### ③ 1인 개발 리소스·스코프 관리

**해결**: MVP 스코프를 **MPM 단일 솔버 + 5~10개 물질**로 엄격히 제한.
- 초기 5종: 물·점성액·모래·연기·촛농
- 추가 5종: 미정 (외부 검증 단계에서 확장)
- 다중 솔버 stitch는 Phase 2 이후로 미룸.

## 기대효과 (도전제안서 4.1)

| 대상 | 효과 |
|------|------|
| 인디 개발자 | 시간·비용 절감 |
| 인디 팀 워크플로우 | VFX 전담 없이 개발 가능 (사이클 단축) |
| 게임 산업 생태계 | 인디 시장 진입 장벽 하락 |
| 본인 & 팀 | 첫 사용자 = 팀 리더. [[mythrill-rpg-showcase]] 출시가 도구의 실증 사례·마케팅 자산 |

## 성장목표 (도전제안서 4.2)

- **단기**: 언리얼 5 플러그인 형태 배포, 물질 20종+ 확장
- **중기**: 엔진 독립 앱으로 전환, 유니티 등 타 엔진 지원
- **장기**: VFX 생성·시뮬·베이킹을 엔진 외부에서 완결하는 독립 파이프라인 플랫폼

이는 [[mythrill-roadmap]]의 Phase 1→2→3 매핑과 일치. 제안서 외부 발표용 단계 표현은 [[mythrill-roadmap]] "피칭 전략" 참조.
