# C-Chasm Alpha (2D 프리퀄)

## 개요

C-Chasm Alpha는 [[C-Chasm]] IP의 **첫 번째 출시작**이자 2D 프리퀄이다. IP 시간선의 선사시대를 무대로 하며, [[C-Chasm_우주론]]에서 패턴 안정도가 가장 낮은 시기를 배경으로 한다 ([[c-chasm-ip-core]] Part 4 참조).

| 항목 | 내용 |
|------|------|
| 작품명 (내부) | C-Chasm Alpha |
| 시간선 | 선사시대 (Pre-Mythic Age) |
| 장르 (표층) | 2D 트윈스틱 액션 + 고정 서사 |
| 장르 (심층) | 코스믹 호러 (크툴루 계열) |
| 엔진 | Unity 2D |
| 플랫폼 | PC (Steam) |
| 분량 | 언더테일 0.8~1.1배 |
| 개발 기간 | 14~18개월 |
| IP 내 순위 | 1순위 ([[본편_RPG_(C-Chasm)]] 이전 선출시) |

## 세계관

### 무대

- **시간대**: 선사시대. 정렬 임계가 역사적으로 가장 낮은 시기
- **공간**: 지구. 혼돈 결합 세계 (사막+빙하+용암+암흑 등)
- **인간**: 부재. 인간형 초기 고대 생명체만 존재
- **인간 컬트 문헌**: 없음. 네크로노미콘 등 금서 미등장

### 주인공

Hypnos (작품문서 예정, 현재 미작성) 의 꿈에서 태어난 존재. 인간이 아니며, 매크로 팩션 구조([[c-chasm-ip-core]] Part 1-4 참조) 의 엘더갓 진영 안정화 벡터의 국소 연장 기관이다. Hypnos 가 꿈속에서 우선순위 지시를 내리며, 주인공은 거부 가능하나 거부 시 안정화 작용이 어긋난다.

## 3분기 루트 구조

```
기본 플레이 (Hypnos 명령 수행)
 ├── [질서 루트] 정렬 강화 → 하스터 봉쇄
 ├── [혼돈 루트] 정렬 해제 → 하스터 해방
 └── [진엔딩 루트] 숨겨진 조건
      ├── Ithaqua 접근 (아우터갓 내부 파벌 충돌)
      ├── Ubbo-Sathla 살해
      ├── 엘더 기록(석판) 노출 → 파편화
      ├── Hypnos의 배신
      └── 주인공 → 석판 수호자로 강제 변모
```

## 등장 개체

### 직접 등장 (보스·조우)

- **하스터**: 최종 보스 (기본·혼돈 루트)
- **크툴루**: 중간 보스
- **나이알라토텝**: 꿈속 직접 접촉
- **Tsathoggua의 화신**: 지하 구역 보스
- **다곤 & Deep Ones**: 해양 구역 보스
- **Ubbo-Sathla**: 진엔딩 살해 대상
- **Ithaqua**: 진엔딩 조력자
- **Hypnos** (작품문서 예정, 현재 미작성): 꿈속 내레이션

## 로어 전달 메커니즘

인간 부재로 인해 독특한 방식 사용:
- **환경 서사**: 유적·지형·기호의 시각적 해석
- **Hypnos 꿈속 내레이션**: 단일 왜곡 층위 (진엔딩에서 불일치 드러남)
- **존재론적 감각**: 크툴루·나이알라토텝 등 조우 시 비언어적 감지

## 본편과의 연결

- 기본: 이스터에그 수준 (환경 모티프·로그·시각 패턴)
- 진엔딩: 서사축 연결 — 석판 파편이 본편 시대까지 잔존, [[본편_RPG_(C-Chasm)]]의 [[dual-ending-branch]]를 매개
