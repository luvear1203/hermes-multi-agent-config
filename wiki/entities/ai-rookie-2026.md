# 인공지능 루키 대회 2026

## 기본 정보

- **대회명**: 인공지능 루키 대회 2026
- **상위 대회**: 전국민 AI 경진대회
- **주최**: 과학기술정보통신부
- **공동 주관**: 정보통신산업진흥원, 한국정보통신기술협회
- **참가 트랙**: 일반 트랙 (모델·API 제한 없음)
- **신청 마감**: 2026-05-08

## 참가 자격

- 만 34세 이하 학사학위 미소지자
- 단일 대학 소속 무관, 자유 팀 구성
- 개인당 최대 3개 팀 중복 참여 가능

## 주요 규정

- **제8조 4항**: 마감 후 구성원 변경 불가 → 팀원 합류 마감 전 확정 필수
- **제8조 7항**: 본선 평가 전까지 1회 트랙 변경 가능
- **제19조**: 재현성 검증 대상 → 원본 데이터 보관 필수
- **제21조 3항**: 오픈소스 저작권 위반 등 자격 상실 사유

## 도전제안서 수정본 핵심 내용

- **2.2 차별점**: ① 파이프라인 단순화 ② [[naked-viewer]] 사전 확인 ③ 실시간 커스텀
- **3.1 구현방법**: Python + Taichi MPM (MIT) + 구성방정식 동적 교체 (Carreau-Yasuda / Arrhenius)
- **3.2 도전과제**: ① LLM → SI 단위 정밀도 ② 시뮬→베이크 품질 보존 ③ 1인 리소스·스코프
- **3.3 추진일정**: 2026.5~6 2차 스파이크 → 7~8 MVP → 9~10 언리얼 연동 → 11~2027.1 외부 검증 → 2027.2~3 공개 배포
- **4.2 성장목표**: 단기 언리얼 플러그인 + 물질 20종 / 중기 엔진 독립 앱 / 장기 독립 파이프라인 플랫폼
